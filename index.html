The entire scoring contract

min(99, 11 × features + 7 × echoes + (features > 0 ? 35 : 0))

Inputs are integers 0–8. Evidence always equals zero. The numbers are arbitrary comedy props, not probabilities.

Small language. Large leap.

Local word trigram sampling from a hand-written fictional corpus. No network calls, API keys, repository scans, trained neural weights or actual LLM. All names and accusations in this demo are fictional.

What would matter?

Specific matching material, commit history, access, dates, licensing and independent corroboration. A feature match or a chatbot's agreement establishes none of those by itself.

The hardware department

A small 6502 instruction interpreter executes assembled kernel bytes in the browser. The other languages run as separate reference programs. This is not a full Commodore 64 emulator.
